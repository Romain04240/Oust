# Oust! 0.3.0

Oust! 0.3.0 brings storage and battery into two optional menu bar indicators, makes the
main tools easier to review, and adds clearer diagnostics. It is a substantial step
forward in an actively developed app, not a completed 1.0.

## Storage and battery, separately

- Choose storage, battery, both, or hide the indicators. Each enabled indicator has
  its own compact panel, with layouts that adapt to their contents and screen space.
- Review charge, power source, available time estimates, battery health and cycles.
  Temperature supports Celsius and Fahrenheit. Available voltage, current and power
  readings are shown with estimates identified.
- See supported peripherals, including separate AirPods earbud/case values when
  available. Choose up to six displayed devices, their order, aliases and eligible alerts.
- Apple Watch values can arrive through an already-paired iPhone. They are marked
  **Via iPhone**; collection time is not sensor measurement time. Relayed values do
  not trigger battery-threshold alerts.
- Battery settings now separate display preferences, Mac alerts and devices.
  Reordering or collapsing a device keeps its configured alert and threshold visible.

Device support and available readings depend on macOS, permissions and the connected
hardware. Missing or stale data stays unavailable rather than becoming a fresh reading.

## A calmer storage review

- Overview is more compact. Opening it collects startup-disk findings once per session
  when needed, or reuses a completed analysis from this session. Automatic collection
  does not select or clean anything; other disks are analyzed on request.
- File classification has its own source date and explicit refresh. APFS container
  measurements stay attached to the requested volume, including rapid volume changes.
- Stop, retry and late-result handling preserve manual choices. An older browser
  read cannot overwrite a newer collection.
- The Bin remains reachable when a selected supported action has no known gain yet.
- The startup-disk guided review covers twelve tools, with Review, Skip, Pause and
  Resume. Finishing the guide does not start cleanup.
- Frequently used tools can be pinned in the sidebar. Application details include
  architecture badges.

## Clearer tools and diagnostics

- Explanations move into contextual help while current protections, errors and
  unavailable actions remain visible.
- Explorer uses a consistent blue surface. Large & old files has one scrollable row
  of file categories with mouse-accessible arrows.
- Advice descriptions expand in place. Archive and duplicate controls have nearby
  explanations without changing their action availability.
- System inspection makes read-only states explicit for user logs, preference
  diagnostics, account archives, iOS backups and other protected data.
- Login Items adds a **partial declared inventory** of applications and helper
  components. Enabled and Allowed are separate states, with unknown values kept
  explicit. A declared entry does not prove that it started.
- The existing targeted missing-path login diagnostic stays separate. macOS Login
  Items settings remain the reference.
- Unreadable Firefox profile inventory is distinguished from confirmed removal.
  Login diagnostic commands can be cancelled without publishing late results.
- Storage graphics and selection feedback respect Reduce Motion.

## What remains unavailable

Generic file cleanup is deliberately blocked in this release. This includes:

- Direct file deletion, including generic cache and build-artifact removal.
- Finder/FileManager Trash operations and history restoration.
- Application uninstalling and removal of leftover files.
- Archive and transfer workflows.
- Compression and replacing duplicates with APFS clones.
- Cloud-file deletion and local-copy eviction.
- Git worktree removal/pruning.

These tools can still help you inspect data. Their sizes do not represent space that
Oust! can necessarily recover, and no permission switch unlocks the blocked methods.
This release does not promise full coverage of every maintenance or cleaner product.

Dedicated operations remain available when their own guards allow them: eligible
simulators and runtimes, supported tool versions, Homebrew cleanup, local container
operations, Firefox history, PhotoKit actions and Time Machine operations. External-disk
erase/partition tools have their own explicit destructive-action checks.

PhotoKit and system-tool operations are not universally reversible. Photos may retain
items in Recently Deleted before storage is recovered; Photos iCloud can propagate
deletion to other devices. History records outcomes; restoration remains unavailable.

## Install and update

Requires **macOS 26 or later**. Release builds target Apple Silicon and Intel; the
published installer's architecture details describe the delivered package.

Download [Oust-0.3.0.dmg](https://github.com/Romain04240/Oust/releases/download/v0.3.0/Oust-0.3.0.dmg)
from [GitHub Releases](https://github.com/Romain04240/Oust/releases). Quit Oust!, open the disk
image and replace the app in Applications through Finder.

You can also request **Check for Updates** in the app. It checks a stable GitHub release,
downloads the matching DMG on request, verifies its size, the published SHA-256 when
present, and the publisher's Developer ID signature before opening it.
Installation remains manual. There is no silent updater or Sparkle integration.

The optional administrator helper still requires macOS approval. A changed helper may
need the explicit repair offered in Settings after installation.

## Privacy and license

File analysis stays on the Mac, with no analytics, telemetry or file inventory sent.
Requested updates contact GitHub. Optional Bluetooth/iPhone relay readings and explicitly
requested iCloud previews have their own local-device or PhotoKit communication.

Oust! is free, available in English and French, and licensed **GPL-3.0-only**.
